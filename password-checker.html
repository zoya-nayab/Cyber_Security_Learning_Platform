💡 Tips for a stronger password

  • Use a passphrase: 4 random words are stronger than a short complex password
  • Never use personal info — birthdays, names, or pet names are guessed first
  • Use a different password for every account
  • Store passwords in a manager like Bitwarden — never in plain text
